# Guitar Inventory Management System (OOP Java)

An Object-Oriented software engineering application in Java designed to search, filter, and manage musical instrument inventory using modular, extensible software architecture principles.

## 📌 Key Engineering Concepts
- **Encapsulation:** Protects instrument specifications, serial numbers, and pricing models.
- **Modular Search:** Decoupled inventory search matching customer preferences against instrument attributes.
- **UML Architectural Model:** Includes structural object-level diagram (`object level diagram.jpg`).

## 📂 Repository Structure
```
gis_java/
├── Guitar.java                  # Instrument entity class
├── GuitarinventorySystem.java   # Inventory catalog management & search engine
├── Main.java                    # Entry point & execution driver
├── object level diagram.jpg     # Object-level UML diagram
└── README.md
```
